## 📌 Overview

This project is a **Java Spring Boot** web application containerized using **Docker**. It demonstrates how to build a Java application, package it into a Docker image, and run it as a container — a key skill in modern DevOps pipelines.

---

## 🧠 What Problem Does This Solve?

Running Java apps on different machines causes the classic **"works on my machine"** problem.

This project solves that by:

- **Dockerizing** the Spring Boot app — runs the same on any machine
- Using **Maven (pom.xml)** to manage dependencies and build the JAR
- Creating a **Dockerfile** to package and run the app in a container

---

## 🗂️ Project Structure

| File/Folder | Purpose |
|-------------|---------|
| `src/` | Java source code — controllers, services, main app |
| `target/` | Compiled JAR file generated by Maven build |
| `Dockerfile` | Instructions to build the Docker image |
| `pom.xml` | Maven config — dependencies, build settings |

## 🚀 How to Run

### Prerequisites
- Java 11+ installed
- Maven installed
- Docker installed

### Step 1 — Build the JAR with Maven
```bash
mvn clean package
docker build -t java-demo-app .
docker run -p 8080:8080 java-demo-app
http://localhost:8080
# View running containers
docker ps

# View all images
docker images

# Stop the container
docker stop <container-id>

# Remove the container
docker rm <container-id>

# Remove the image
docker rmi java-demo-app
